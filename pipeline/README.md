# Pipeline – mesterpromptern

Brukes av ukesløpet (prosjektdokument claude/mesterpromptern/agent-ukeslop.md).

- `mp_reel.py` – renderer. `python3 mp_reel.py render manusbank.md 001,002 OUTDIR`
- `manusbank.md` – manus, format `id|serie|topp|bunn`
- `used_ids.txt` – brukte ID-er. Bruk aldri en ID herfra igjen.
